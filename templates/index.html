Integrated Bioinformatics Pipeline

Designed specifically to provide a transparent, reproducible, and verifiable journey from high-throughput omics data to candidate biomarkers.

1
Data QC & Preprocessing

Upload or load gene expression matrices and sample metadata. Verifies column alignment, sample ID parity, handles missing data, detects duplicate genes, and infers log2 vs raw count formats.

  • Strict metadata parity validation
  • Median/drop missing values
  • 1-Click Microarray & RNA-seq Demos
2
Differential Expression & GSEA

Executes linear models and Empirical Bayes moderation via R limma (or DESeq2 for RNA-seq counts). Computes log2FC and Benjamini-Hochberg FDR, with an interactive Plotly Volcano plot and GSEApy pathway enrichment.

  • Native Rscript invocation
  • Configurable FDR & log2FC cutoffs
  • KEGG, GO, & Reactome enrichment
3
PPI Network & Hub Genes

Queries the STRING DB API for functional protein associations, constructs an interaction graph via NetworkX, calculates Degree & Betweenness centralities, and ranks candidate hub genes using a composite scoring model.

  • Customizable confidence threshold
  • Force-directed 2D interactive graph
  • Ranked hub genes table & CSV export
4
Validation & HTML Report

Evaluates candidate biomarkers using regularized Logistic Regression with Stratified Cross-Validation. Strictly encapsulates feature scaling in CV folds to prevent data leakage. Generates standalone HTML Capstone reports.

  • Strict leakage prevention pipeline
  • ROC-AUC, Confusion Matrix, F1-score
  • Standalone HTML & CSV exports
