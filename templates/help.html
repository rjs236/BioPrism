1. Pipeline Philosophy & Rationale

Modern high-throughput genomics generates expression levels across tens of thousands of genes simultaneously, yet typical biomedical cohorts suffer from the "curse of dimensionality" ($p \gg n$, where the number of features $p \approx 20,000$ vastly exceeds the number of biological replicates $n \approx 10 - 100$).

BioPrism addresses this challenge through a multi-tiered filtering cascade:

  1. Rigorous Preprocessing: Verification of sample identifier parity, median imputation, and automatic format identification.
  2. Empirical Bayes Linear Modeling: Statistically borrowing variance information across all genes using R limma (or negative binomial modeling with DESeq2 for raw counts).
  3. Biological Contextualization: Connecting significant genes via STRING database functional associations and identifying topologically indispensable hub nodes.
  4. Leakage-Free Validation: Nested cross-validation with feature scaling strictly isolated within training folds to evaluate true generalization capacity.

2. Differential Expression: Limma vs. DESeq2

R limma (Microarray & Normalized Log2)

In standard Student's t-tests, gene-wise sample variances $s_g^2$ calculated on small sample sizes ($n=3-10$) are unstable, resulting in elevated false positives for genes with artificially small variances.

Limma's Empirical Bayes: Shrinks sample variances towards a common global prior $s_0^2$: $$\tilde{s}_g^2 = \frac{d_0 s_0^2 + d_g s_g^2}{d_0 + d_g}$$ This moderated t-statistic produces robust p-values that withstand small-sample fluctuations.

R DESeq2 (Raw RNA-seq Counts)

RNA-seq counts are discrete integers that exhibit overdispersion (variance exceeds the mean), violating normal distribution assumptions.

Negative Binomial Modeling: DESeq2 models counts with: $$K_{gj} \sim \text{NB}(\text{mean} = \mu_{gj}, \text{dispersion} = \alpha_g)$$ and uses median-of-ratios size factor normalization to adjust for differing library depths.

3. False Discovery Rate (Benjamini-Hochberg)

When testing 20,000 genes at an unadjusted significance level $\alpha = 0.05$, one expects $20,000 \times 0.05 = 1,000$ false positives purely by chance.

BioPrism implements the Benjamini-Hochberg (BH) step-up procedure to control the False Discovery Rate (FDR):

1. Sort raw p-values: P(1) ≤ P(2) ≤ ... ≤ P(m)
2. Calculate critical value: (i / m) × Q
3. Find largest rank k such that P(k) ≤ (k / m) × Q
4. Declare all genes with rank i ≤ k as statistically significant.

4. STRING Database Functional Association Scores

The STRING database integrates evidence from multiple distinct channels:

  • Genomic Context: Gene neighborhood, gene fusion, and phylogenetic co-occurrence.
  • High-Throughput Experiments: Affinity purification, yeast two-hybrid, mass spectrometry.
  • Conserved Co-Expression: Correlated transcript patterns across heterogeneous conditions.
  • Automated Text Mining: Joint mentions of protein pairs in PubMed abstracts.
Confidence Thresholds: A STRING combined score $S \ge 400$ indicates medium confidence (roughly 50% probability that interaction is biologically genuine); $S \ge 700$ reflects high confidence, and $S \ge 900$ reflects highest confidence.

5. Network Topologies & Composite Hub Ranking

NetworkX is utilized to construct a graph $G = (V, E)$ where nodes $V$ represent proteins and edges $E$ represent interactions weighted by confidence score.

Degree Centrality ($C_D$)

Measures direct connectivity: $C_D(v) = \frac{\text{deg}(v)}{|V| - 1}$. High degree nodes serve as master biological coordinators.

Betweenness Centrality ($C_B$)

Measures bottleneck influence: $C_B(v) = \sum_{s \ne v \ne t} \frac{\sigma_{st}(v)}{\sigma_{st}}$. Proteins with high betweenness bridge disparate cellular functional modules.

BioPrism Composite Hub Score Formula

To prioritize genes that are both topologically influential AND statistically dysregulated, BioPrism integrates: $$\text{Hub Score} = 0.45 \times \frac{\text{Degree}}{\text{Max Degree}} + 0.35 \times C_B(v) + 0.20 \times \min\left(1.0, \frac{|\log_2 \text{FC}| \cdot (-\log_{10} \text{FDR})}{10}\right)$$

6. Machine Learning Data Leakage Prevention

A catastrophic flaw in naive bioinformatics machine learning pipelines is data leakage: scaling features or normalizing the entire dataset before splitting into train and test folds. This leaks information about the mean and variance of the test set into the model, leading to spuriously inflated accuracy.

BioPrism's Leakage-Free Architecture

BioPrism strictly utilizes sklearn.pipeline.Pipeline inside stratified cross-validation folds: 

pipeline = Pipeline([
    ('scaler', StandardScaler()),       # Scaler fits ONLY on X_train fold
    ('classifier', LogisticRegression(class_weight='balanced'))
])
# Test fold X_test is transformed using parameters from X_train!

7. Clinical Validity Boundaries

Key Scientific Takeaway for Capstone Reviewers:
High classification accuracy (e.g. ROC-AUC > 0.90) in a discovery cohort demonstrates statistical discriminative power within that dataset. It does not establish clinical diagnostic utility. True translation requires:
  • Analytical Validity: Assay repeatability and precision across laboratories.
  • Clinical Validity: Blinded prospective testing in multi-center clinical trials.
  • Orthogonal Biological Assays: Molecular verification via RT-qPCR, Western blot, or Immunohistochemistry (IHC).

8. Capstone Oral Defense Q&A

Standard t-tests perform poorly when sample size is small because variance estimation per gene is erratic. Limma's Empirical Bayes methodology estimates prior variance parameters across all genes simultaneously, effectively moderating extreme variance outliers and providing substantially higher statistical power.

If continuous normalized data (e.g. TPM / FPKM) is uploaded with large non-log values (range > 30), BioPrism automatically applies $\log_2(x + 1)$ transformation to stabilize variance for linear modeling. If integer counts are uploaded, DESeq2 negative binomial modeling is recommended and executed.

A direct physical interaction means two proteins bind to form a complex (e.g. demonstrated by X-ray crystallography or co-immunoprecipitation). A functional association includes proteins operating in the same biological cascade, sharing transcription factors, or showing co-expression, even if they do not physically touch.
